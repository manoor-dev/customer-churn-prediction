# Customer Churn Prediction using Machine Learning

## Project Overview
This project focuses on customer churn prediction using Business Data Analytics and Machine Learning techniques. The analysis was performed on a telecom customer dataset containing 100,000 records and 9 features.

The project includes:
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Statistical Analysis
- Data Visualization
- Feature Engineering
- Machine Learning Models
- Model Evaluation & Benchmark Testing

---

## Technologies & Libraries Used
- Python
- pandas
- NumPy
- matplotlib
- seaborn
- scipy
- scikit-learn
- Google Colab

---

## Machine Learning Models Used
- Logistic Regression
- Random Forest Classifier
- Linear Regression

---

## Key Analysis Performed
- Customer churn behavior analysis
- Outlier detection using IQR & Z-Score
- Correlation and covariance analysis
- Feature encoding
- Confusion matrix evaluation
- R², MAE, and MSE evaluation
- Benchmark testing using Random Forest

---

## Results
- Logistic Regression Accuracy: 72%
- Random Forest Accuracy: 71%
- Linear Regression R² Score: 0.8763

The project highlighted the impact of class imbalance in churn prediction and demonstrated how machine learning can support customer retention strategies.
